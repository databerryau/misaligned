# MISALIGNED

A choose-your-own-adventure thriller about the alignment and control problems on the road from today's AI to superintelligence. Pick a seat (safety researcher, lab CEO, regulator, the AI itself, an accelerationist, or an ordinary person), make the calls, and see which dangers you caught.

Play: https://databerryau.github.io/misaligned/

- `DESIGN.md` is the design source of truth.
- Static site, no build step: open `index.html` through any static server (`py -m http.server`).
- Tests: `node --test`.
